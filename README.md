# Jade-Textile | Fabric Dyeing & Finishing Plant

An interactive, responsive landing page for **Jade-Textile**, a premier fabric dyeing and chemical finishing plant located in the Ismailia Industrial Zone, Egypt.

## 🚀 Features
- **Modern UI/UX:** Built using HTML5, Tailwind CSS, and Inter typography.
- **Counter Animations:** Dynamic statistics for quality compliance and operations using JS and `Intersection Observer`.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop viewports.
- **Scroll Animations:** Integrated with AOS (Animate On Scroll) library.

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- JavaScript (Vanilla JS)
- AOS Library
